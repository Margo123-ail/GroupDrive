GROUPDRIVE — ИНСТРУКЦИЯ (версия с ролями, проверкой и почтой)

1. УСТАНОВКА НА WINDOWS
- Установи Node.js LTS (версия 18 или новее) с официального сайта: https://nodejs.org/
- Распакуй архив в отдельную папку, например C:\GroupDrive_Ready.
- Открой эту папку в Проводнике, нажми адресную строку, введи powershell и нажми Enter.
- Выполни команды:
    npm install
    Copy-Item .env.example .env
- Открой .env в Блокноте и настрой SEED_ADMIN_NAME, SEED_ADMIN_EMAIL, SEED_ADMIN_PASSWORD.
  Используй свой email администратора и уникальный сильный пароль. Не публикуй .env и не отправляй его другим.
- Задай SESSION_SECRET длинной случайной строкой (не меньше 32 символов).
- Для запуска выполни:
    npm start
- Открой http://localhost:3000

2. ПОЧТА: БЕЗ ПАРОЛЯ ОТ ЛИЧНОЙ ПОЧТЫ
Для отправки писем подтверждения и восстановления нужен внешний почтовый сервис. Этот проект поддерживает Brevo API.
- Создай аккаунт на https://www.brevo.com/ (ничего через PowerShell скачивать не требуется).
- В Brevo добавь и подтверди адрес отправителя. Для стабильной доставляемости настрой домен, если у тебя есть собственный домен.
- В настройках API сгенерируй API key.
- В .env заполни BREVO_API_KEY, MAIL_FROM (подтверждённый email отправителя) и при желании MAIL_FROM_NAME=GroupDrive.
- Перезапусти сервер (Ctrl+C, затем npm start).
- Если Brevo не настроен, приложение только печатает ссылки в консоль сервера — письма реальным пользователям НЕ отправляются.
- Когда сайт будет размещён в интернете, укажи публичный адрес в APP_URL, например https://твой-домен.example. Не оставляй localhost в продакшене.

3. РОЛИ
- Администратор создаётся из SEED_ADMIN_EMAIL/SEED_ADMIN_PASSWORD. Если в базе уже есть пользователь с указанным SEED_ADMIN_EMAIL, его роль будет повышена до admin; пароль останется прежним.
- Вход администратора выбирается на странице входа. Панель: /admin.html.
- Только администратор создаёт преподавателей. Для каждого задай временный пароль длиной минимум 12 символов и передай его преподавателю безопасным способом.
- Ученики регистрируются самостоятельно через /register.html; публичная регистрация всегда создаёт только роль student.
- Преподаватели и администратор могут просматривать и проверять работы. На странице /reviews.html выбирается статус и комментарий.
- Все авторизованные пользователи могут создать ссылку на файл, принадлежащий им. Преподаватели/администратор могут делиться доступными им файлами.
- Преподаватель или администратор может запрещать/разрешать скачивание файла. Публичная ссылка не должна обходить запрет скачивания.

4. ВАЖНО О ДАННЫХ И ПУБЛИКАЦИИ
- База находится в data/groupdrive.db, файлы — в uploads/. Делай резервные копии этих данных.
- Не загружай .env, data/, uploads/ или базу с личными работами на GitHub.
- GitHub Pages не запускает этот Node.js сервер и не хранит SQLite как полноценное приложение. Нужен хостинг Node.js с постоянным хранилищем для базы и загруженных файлов.
- Для публичного сайта обязательно HTTPS, длинный SESSION_SECRET и корректный APP_URL.

5. ПРЕДЕЛЫ
- Запрет скачивания блокирует обычную кнопку скачивания и ссылки загрузки внутри GroupDrive, но технически нельзя полностью запретить человеку сохранять то, что браузер уже может показать (например, видео или изображение).
- Этот архив проверен на синтаксис Node.js; полноценный тест доставки писем нужно выполнить после ввода настоящего Brevo API key и подтверждённого отправителя.
